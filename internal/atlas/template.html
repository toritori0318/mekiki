How to read this

Two marks carry most of the meaning: the tier and the contract dots.

Maturity tier — cumulative, each level measured by rules

○○○T0 exists Either the basics carry an error (name, description, lifecycle wording) or the Contract is not complete.
●○○T1 declared Basics clean and all six Contract entries present — the minimum for a new skill.
●●○T2 safe Nothing unsafe left: no arithmetic in prose, guards actually invoked, scripts tested, billable work not model-startable.
●●●T3 verified Both official eval formats present — output quality and trigger accuracy — and, where a run was recorded in evals/results.json, it passed.
Nothing applicable counts as satisfied — a knowledge skill with nothing to guard reaches T2, because having nothing to guard is a safe state. The tier is a headline; per-axis truth is in the badges below.

Contract — the six dots, filled when the entry is written

Triggerwhen this skill should run
Inputswhat it needs, and where that comes from
Preconditionswhat must already be true
Outputswhat it writes
Postconditionshow "done" is judged
Non-goalswhat it deliberately does not do, and which skill owns that instead
Non-goals is the load-bearing one: it is what stops a skill reaching into the next one's work.
